# 🎬 Movie Ticket Booking System

A simple **Python-based Movie Ticket Booking System** that allows users to view available movies, book tickets, calculate the total amount, and store booking records in a CSV file.

## 🚀 Features

* 🎬 View available movies
* 🎟️ Book movie tickets
* 👤 Enter customer details
* 🔢 Select number of tickets
* 💰 Automatic ticket price calculation
* 📄 Store bookings in CSV format
* 📋 View previous bookings
* ❌ Input validation
* 🖥️ Simple command-line interface

## 🛠️ Technologies Used

* **Python**
* **CSV**
* **File Handling**
* **Functions**
* **Dictionaries**
* **Loops**
* **Exception Handling**

## 🎯 How It Works

The system provides a menu with the following options:

```text
1. Show Movies
2. Book Ticket
3. View Bookings
4. Exit
```

When a user books a ticket, the program automatically calculates the total amount:

```text
Total Amount = Ticket Price × Number of Tickets
```

Booking information is stored in `bookings.csv` for future reference.
